nAI Client

## To start Inityialize Vite server
npm create vite@latest nAI-client

## To start Vite Server
/nAIsrc/apps/client$ npm run dev


## Server Start

docker compose up --build

docker compose down






Top Level folders

| Folder           | Responsibility                           |
| ---------------- | ---------------------------------------- |
| `apps`           | Applications                             |
| `services`       | Backend business services                |
| `packages`       | Reusable libraries                       |
| `infrastructure` | Databases, containers, cloud, deployment |
| `scripts`        | Automation/utilities                     |
| `docs`           | Documentation                            |
| `.github`        | CI/CD                                    |
